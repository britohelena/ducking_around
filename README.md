## Notas técnicas
- Páginas estáticas em HTML/CSS/JS puro, sem build step.
- Persistência de dados via `firebase-config.js` (Firestore), com fallback automático para `localStorage` quando o Firebase não está disponível.
- Tema da página inicial: floresta à noite (verde escuro, lua e pirilampos).
